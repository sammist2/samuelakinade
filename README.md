# Samuel Akinade — Professional Profile

This repository hosts Samuel Akinade's personal professional-profile website:
a single, self-contained static page (`index.html`) with its markup, styles,
and assets inlined, so it needs no build step and no dependencies.

## Viewing it

- **Locally** — open `index.html` directly in any web browser, or serve the
  folder and visit the printed URL:

  ```bash
  python -m http.server 8000   # then open http://localhost:8000
  ```

- **Hosted** — because the page is fully static, it can be published with
  GitHub Pages (Settings → Pages → deploy from the `main` branch) or any
  static web host.
